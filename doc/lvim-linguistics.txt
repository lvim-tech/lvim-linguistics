1. INTRODUCTION                                   *lvim-linguistics-intro*

lvim-linguistics controls two things, useful when writing in a foreign
language:

  • Spelling — enables 'spell' with a chosen language on allowed buffers and
    downloads the dictionary (.spl) on demand from the Vim FTP mirror.
  • Insert-mode keyboard language — flips the OS keyboard layout on
    InsertEnter and restores it on InsertLeave, gated per filetype.

Both features honour a per-filetype allow-list: a `black_list` (never active
there) and, when non-empty, a `white_list` (active ONLY there). The active
profile is per working directory: a global layer applies everywhere and a
project-local one overrides it (see |lvim-linguistics-local|).

==============================================================================
2. REQUIREMENTS                             *lvim-linguistics-requirements*

  • Neovim >= 0.10
  • lvim-utils (palette + merge + the settings store)
  • lvim-ui (the settings panel)
  • curl (to download spell files / dictionaries)
  • a keyboard-layout switch tool for your session, auto-detected:

    Session              Tool
    -------------------  ------------------------------------------------
    X11                  xkb-switch
    Wayland — Hyprland   hyprctl
    Wayland — niri       niri
    Wayland — sway       swaymsg
    Wayland — mango      mmsg
    Wayland — GNOME      gdbus

Run |:checkhealth| lvim-linguistics to verify the tools (see
|lvim-linguistics-health|).

3. SETUP                                          *lvim-linguistics-setup*
>lua
  require("lvim-linguistics").setup({
      plugin_config = {
          -- string prefix ("xkb-switch -s ") or a function of the layout id;
          -- auto-detected from the session when omitted.
          kbrd_cmd = "xkb-switch -s ",
          spell_files_folder = os.getenv("HOME") .. "/.config/nvim/spell",
      },
      base_config = {
          mode_language = {
              active = false,
              file_types = { black_list = {}, white_list = {} },
              normal_mode_language = "us",
              insert_mode_language = "bg",
              insert_mode_languages = { "bg", "de", "fr" },
          },
          spell = {
              active = false,
              file_types = { black_list = {}, white_list = {} },
              language = "en",
              languages = {
                  en = { spelllang = "en", spellfile = "en.add" },
              },
          },
      },
  })
<
setup() merges user options into the live config in place (via
lvim-utils.utils.merge — a clean array REPLACE, so a user `black_list`
REPLACES the default rather than being appended), registers the highlight
groups, loads the runtime state for the cwd, then installs the command and
autocmds on the next tick.

==============================================================================
4. CONFIGURATION                                 *lvim-linguistics-config*

plugin_config ~
  kbrd_cmd            Keyboard-switch command. A string PREFIX to which the
                      layout id is appended (`kbrd_cmd .. lang`), or a
                      function `fun(lang):string` returning the full command
                      (use this for index-based switchers like Hyprland).
  spell_files_folder  Directory where .spl/.sug spell files live (downloaded
                      automatically on first use).

base_config.mode_language ~
  active                 Whether insert-mode layout switching starts on.
  file_types.black_list  Filetypes where switching NEVER runs.
  file_types.white_list  If non-empty, switching runs ONLY in these filetypes.
  normal_mode_language   Layout id restored on InsertLeave.
  insert_mode_language   Layout id set on InsertEnter.
  insert_mode_languages  Selectable insert-mode layouts (panel dropdown).

base_config.spell ~
  active                 Whether spell checking starts on.
  file_types.black_list  Filetypes where 'spell' is NEVER set.
  file_types.white_list  If non-empty, 'spell' is set ONLY in these filetypes.
  language               Active language key (must exist in `languages`).
  languages              Table of `key = { spelllang, spellfile }`.

5. SETTINGS LAYERS                                 *lvim-linguistics-local*

The runtime profile is three layers, later winning:

  1. `base_config`                          the defaults from setup()
  2. the GLOBAL settings                    every project
  3. `<cwd>/.lvim/linguistics/config.json`  this directory only

Layers 2 and 3 are the same shape — a partial `base_config` — so each carries
only the keys it overrides and everything else falls through.

The GLOBAL layer is not a file of the plugin's own: it is an editor-wide
preference, so it is stored where the rest of them are — the control center's
database. The plugin holds the live values (`lvim-linguistics.store`) and is
told where to persist them: >lua

  local store = require("lvim-linguistics.store")
  store.bind_global(function(key, value)  -- where "permanently" writes
      require("lvim-control-center").get("LvimControlCenter").data:save(key, value)
  end)
  store.set_global(key, value)   -- this session only
  store.save_global(key, value)  -- and persist it
<
Without a binding the global layer is session-only. `store.FIELDS` names the
four settings and where each lands in the config.

The LOCAL layer is the half that cannot live in a one-value-per-name database
(it belongs to a directory, not to the editor), so it stays a document, written
through the shared `lvim-utils.store` json backend and re-read on |DirChanged|.
A document changed on disk by ANOTHER Neovim instance is picked up and
re-applied here.

6. PANEL                                           *lvim-linguistics-panel*

`:LvimLinguistics` opens a two-tab settings panel (built on lvim-ui). Both
tabs carry the SAME rows; the tab chooses where a permanent save lands:

  Global          -> the global layer, for every project
  This directory  -> the local document, for this directory (and it wins)

The model is: EDIT = now, SAVE = forever.

  • Changing a row takes effect immediately and writes NOTHING — close Neovim
    and it is gone. This is exactly what the toggle-* subcommands do.
  • `Save permanently` stores the tab's values in that tab's layer. On the
    local tab it reads `Rewrite this directory's settings` once the document
    exists.
  • `Delete this directory's settings` removes the document, so the global
    layer applies here again. It is inert while there is none.

While this directory has no document of its own, the two tabs are the same
thing: the local tab mirrors the global one live, including edits that have
not been saved yet.

The global rows are the same values the control center edits, when its
settings are wired to this plugin (see |lvim-linguistics-local|).

Panel keys:

  j / k        move down / up
  h / l        previous / next tab
  <Space>      toggle a bool row
  <CR>         confirm / run the focused row
  <Esc> / q    close

==============================================================================
7. COMMAND                                            *:LvimLinguistics*

  :LvimLinguistics                    Open the settings panel.
  :LvimLinguistics global             Open the panel on the Global tab.
  :LvimLinguistics local              Open the panel on the This directory tab.
  :LvimLinguistics toggle-spelling    Toggle spell checking for this session.
  :LvimLinguistics toggle-insert-mode Toggle insert-mode switching for this session.

A trailing `float`, `area` or `bottom` overrides `settings_panel.layout` for
that one open: >

  :LvimLinguistics local bottom
<
The command name itself is `settings_panel.command`.

==============================================================================
8. SPELL FILES                                *lvim-linguistics-spellfiles*

Dictionaries (`<lang>.utf-8.spl`) and, when Neovim raises |SpellFileMissing|,
the matching `.sug`, are downloaded automatically (non-blocking) from
https://ftp.nluug.nl/vim/runtime/spell/ into `spell_files_folder`. A
notification appears when the file is ready.

==============================================================================
9. STATUSLINE                                *lvim-linguistics-statusline*

Two providers, for a statusline component:
>lua
  local status = require("lvim-linguistics.status")
  status.spell_has()   -- boolean: 'spell' on in the current window
  status.spell_get()   -- "KEY (SPELLLANG)" (upper-cased) or nil
<

10. HIGHLIGHTS                              *lvim-linguistics-highlights*

Built from the lvim-utils palette and rebuilt on colorscheme change:

  LvimLinguisticsIcon          General icons (teal)
  LvimLinguisticsSpellActive   Active spell indicator (green)
  LvimLinguisticsSpellLang     Language name (blue)
  LvimLinguisticsSpellSep      Separator (blended blue)
  LvimLinguisticsLangActive    Active insert-mode language (purple, bold)
  LvimLinguisticsLangNormal    Normal-mode language (teal)
  LvimLinguisticsLangInsert    Insert-mode language (yellow)

Override any group with `vim.api.nvim_set_hl(0, "<Group>", { ... })`.

11. HEALTH                                       *lvim-linguistics-health*

spell-file folder, curl, and the loaded runtime state.
